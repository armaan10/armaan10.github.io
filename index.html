Selected Projects

Scalable Processing and Analysis of Large-Scale High Performance Computing Logs

For my master's project I built a high throughput log processing pipeline for analyzing 2.4TB of system logs from the MIT Supercloud Cluster. The processed logs are used to identify a variety of trends in system and user behavior.

Python Data Analysis

NNViz

A WebGPU-powered tool built for visualizing neural network architectures and training processes. The tool allows users to configure their own neural network and observe how it evolves during training. Neuron activation and edge weights are color-coded to represent their magnitude and sign. Backpropagation is visualized as a wave travelling through the network.

TypeScript WebGPU GPU Acceleration

Distributed Algorithms Simulator

Built an end-to-end distributed algorithms simulator using Scala and Akka classic actors. Randomly generated graphs are used to define the network topology, where each node is an actor in the distributed system. Itai-Rodeh leader election and ring size estimation algorithms run on top of these networks.

Scala Distributed Systems Akka
